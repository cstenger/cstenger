### 🚀 Featured Project

#### **[allwinner-h713-mainline](https://github.com/cstenger/allwinner-h713-mainline)**
> Mainline boot chain (`U-Boot SPL` → `TF-A BL31` → `U-Boot` → `Linux`) and 64-bit Debian distribution for the **Allwinner H713 (sun50iw12)** SoC and HY200 hardware platforms.
> - **Mainline Linux 6.x** boot from eMMC to full root login with 4-core SMP.
> - **Cedrus Hardware Video Decoder**: Hardware-accelerated H.264 / HEVC video decoding via mainline V4L2 request API.
> - Standalone boot chain, reproducible build orchestrator, signed key-only rootfs, and serial recovery tooling.
